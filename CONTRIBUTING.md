# Contributing

Thanks for helping out! This is a small, deliberately minimal project: the
public API stays close to Cloudflare's own API and to the conventions of the
official [`cloudflare`](https://crates.io/crates/cloudflare) crate.

## Before you start

- **Bugs and small fixes:** a PR is welcome, ideally with a failing test.
- **Features and API changes:** please open an issue first and describe the use
  case. PRs for new features without a prior discussion may be closed.
- Keep PRs small and focused, and justify every new dependency.
- Please read the [Code of Conduct](CODE_OF_CONDUCT.md).

## Checks

CI runs the following; run them locally before pushing:

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
cargo hack check --workspace --feature-powerset   # needs cargo-hack
cargo deny check                                  # needs cargo-deny
```

The minimum supported Rust version is 1.85; don't raise it without discussion.

## Tests

- Most tests run against a local [`wiremock`](https://crates.io/crates/wiremock)
  server, so they need no network or credentials. Add fixtures to
  `crates/cf-images/tests/fixtures/`.
- Tests against the real Cloudflare API live in
  `crates/cf-images/tests/live.rs`. They are `#[ignore]`d, need your own
  account and a token, and are never required for a PR. See the file header
  for how to run them.
- Never commit tokens, signing keys or account IDs.

## Docs and changelog

Update rustdoc for any public API change. Changelogs and version bumps are
generated by [release-plz](https://release-plz.dev) from commit messages, so
use [Conventional Commits](https://www.conventionalcommits.org/)
(`fix:`, `feat:`, `feat!:` for breaking changes). PRs are squash-merged, so the
**PR title** becomes the commit message and CI checks that it is a
Conventional Commit. Only `feat`, `fix` and `perf` trigger a release.
